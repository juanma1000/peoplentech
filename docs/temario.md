# Estructurar el desarrollo de software con IA, mediante harnesses y SDD

**Duración:** 30 min

**Objetivo:** Mostrar cómo estructurar el ciclo de desarrollo de software con agentes de IA, desde el Discovery hasta el Delivery, mediante harnesses que guían y controlan el trabajo de los agentes y un enfoque SDD que convierte las especificaciones en software verificable.

## Agenda

| # | Bloque | Tiempo |
|---|--------|--------|
| 1 | Introducción: agentes y harness | 3 min |
| 2 | Discovery: benchmarking y PRD | 6 min |
| 3 | Arquitectura | 6 min |
| 4 | SDD: de la especificación al código | 8 min |
| 5 | AGENTS.md: el harness base | 3 min |
| 6 | Cierre y preguntas | 4 min |

---

## 1. Introducción: agentes y harness (3 min)

- Cada agente tiene su rol
- Qué es un harness: guía y controla el trabajo del agente
- Ciclo completo: Discovery → Arquitectura → Specs → Implementación → Delivery

## 2. Discovery (6 min)

### 2.1 Benchmarking con Perplexity
Búsqueda en la web para obtener:
- Objetivo de aplicaciones similares
- Valor añadido y ventajas competitivas
- Funciones principales

### 2.2 Generación del PRD
- Objetivo
- Primeras HU (historias de usuario)

## 3. Arquitectura (6 min)

- Patrones de arquitectura
  - Capas
  - Microkernel
  - Microservicios
  - Hexagonal
  - Limpia
  - Eventos
- ADR (Architecture Decision Records)
- Diagramas

> Cuanto mejor sea tu arquitectura, mejor será el código que la IA genera para ti.

## 4. SDD: Spec-Driven Development (8 min)

- Las SPECS son archivos (versionados, revisables)
- Reducir alucinaciones
- Flujo: Specify → Plan → Tasks → Implement
- Specify es el 70% del trabajo
- Specs verificables: criterios de aceptación → pruebas

## 5. AGENTS.md (3 min)

- Instrucciones del sistema generales
- Mantenerlo reducido

## 6. Cierre (4 min)

- Resumen: harness + SDD = software verificable
- Preguntas
