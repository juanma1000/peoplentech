1 · Introducción

Agente + harness

El modelo es el motor; el harness es todo lo que lo rodea, lo guía y lo controla.

SkillsCapacidades empaquetadas que el agente carga solo cuando la tarea las necesita

VerificacionesTests, lint y revisión que validan el resultado antes de entregar
PermisosQué herramientas y comandos puede ejecutar el agente, y cuáles piden aprobación
SubagentesAgentes especializados con rol y contexto propio, delegados por el principal

5 · SDD

Estándares del proyecto: base-standards

Los agentes arrancan por CLAUDE.md (symlink a base-standards.md), que enlaza al resto de reglas, y las usan en cada fase del SDD:

📚 Estándares→ 📝 Specify🗂️ Plan✅ Tasks💻 Implement 
# raíz del proyecto
CLAUDE.md ⇢ symlink a docs/base-standards.md
docs/
├─ base-standards.md         ← entrada: principios, idioma, skills, modelo
├─ backend-standards.md      ← FastAPI, DDD, SOLID, API, testing, seguridad
├─ frontend-standards.md     ← React, microfrontends, UI/UX, testing
├─ documentation-standards.md ← cómo documentar y mantener los AI specs
└─ openspec-tasks-mandatory-steps.md ← checklist obligatorio de tasks.md
.claude/skills/             ← skills del proyecto (draft-prd, draft-architecture…)
PrincipiosPasos cortos, TDD, tipado, nombres claros
IdiomaCódigo en inglés; documentación de proceso en español
Por áreaBackend y frontend con sus propios estándares
5 · SDD

¿Qué hace cada estándar derivado de base-standards?

⚙️ backend-standards
  • FastAPI + DDD y SOLID
  • Diseño de API
  • Base de datos
  • Testing y seguridad
🖥️ frontend-standards
  • React y microfrontends
  • Estructura del proyecto
  • UI/UX
  • Testing
📚 documentation-standards
  • Documentación técnica
  • AI specs
  • Reglas de idioma
✅ openspec-tasks-mandatory-steps
  • Pasos obligatorios en tasks.md
  • Tests unitarios
  • Pruebas manuales ejecutadas por el agente

base-standards fija los principios; cada estándar los baja a su área.
