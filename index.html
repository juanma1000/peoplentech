4 · SDD

Una spec es un archivo

# specs/001-login/spec.md
## HU-001 Como usuario quiero iniciar sesión con correo y clave

### Criterios de aceptación
Dado credenciales válidas
Cuando envío el formulario
Entonces recibo un token y soy redirigido al inicio

Dado credenciales inválidas
Entonces veo "Credenciales incorrectas" y no se crea sesión

Cada criterio se convierte en una prueba: así la spec es verificable.
